## 🚀 Projects

### [Multi-Agent RAG Chatbot](https://github.com/prasad430/AI-rag-bot)
A coordinator classifies each question with Gemini, then contacts only the specialist agents that can actually answer it — health, sports, both, or neither. Each agent runs its own Weaviate semantic search and writes a grounded, cited answer; the coordinator merges them into one reply. Five services, a discovery registry, and a Docker deploy.

`Python` · `FastAPI` · `Gemini` · `Weaviate` · `Docker`

### [AI Resume Screening](https://github.com/prasad430/AI_resume_screening)
Scores candidates against a job description using BERT embeddings, served from a Flask API behind a React + Vite dashboard. Turns a stack of PDFs into a ranked shortlist.

`BERT` · `Transformers` · `Flask` · `React`

### [Employee Management System](https://github.com/prasad430/employee-management-system)
Multi-organization, full-stack platform with JWT authentication and role-based access control — each org sees only its own data.

`React` · `Node/Express` · `MySQL` · `JWT`

### [Task Management App](https://github.com/prasad430/task-management-app)
Full-stack task tracker: Next.js and Material UI on the front, a Node/Express CRUD API behind it.

`Next.js` · `Material UI` · `Node/Express`

### [Heart Disease Analysis](https://github.com/prasad430/Heart_Disease_Analysis)
Exploratory data analysis of a clinical dataset — correlation heatmaps, demographic breakdowns, and what the numbers actually suggest about risk factors.

`Pandas` · `Matplotlib` · `Seaborn`
